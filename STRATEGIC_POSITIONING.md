## 🚦 Decision Framework

### When adding a feature, ask:

1. **Does it enhance core value prop?** (displacement risk or career pathing)
   - YES → High priority
   - NO → Deprioritize

2. **Can we build it in <2 weeks?**
   - YES → Do it now
   - NO → Break into phases

3. **Does it differentiate from competitors?**
   - YES → Competitive advantage
   - NO → Only if users demand it

4. **Does it respect privacy/ethics?**
   - YES → Aligned with mission
   - NO → Hard pass

5. **Can it generate revenue within 6 months?**
   - YES → Business priority
   - NO → Community/growth feature
